# Interview prep practice

Run one timed practice problem, then record the gap to drill next.
Ground truth: [Session loop](references/session-loop.md). Do not invent a
second playbook — extend that doc when the pattern changes.

## Checklist

1. One track per session. State the time box before starting.
2. Restate the prompt, give a brute-force idea, then a better approach, then code or a design. Stop when time is up.
3. Review correctness, complexity, and one cleaner alternative.
4. Write four lines: problem, outcome, gap, next topic. Keep prompts to material the user may reuse.
