# Interview prep practice

## Purpose

Run one timed practice problem, then leave a short record of the gap to drill
next. Keep prompts to material the user is allowed to reuse.

## Steps

1. If the track is not already chosen, ask for one: data structures,
   algorithms, system design, Kotlin or Android, or behavioral. One track per
   session.
2. Pick one problem at the agreed difficulty. State the time box before
   starting. Default to 25 minutes for a coding problem and 20 minutes for a
   design prompt.
3. Work the problem in this order: restate the prompt, give a brute-force
   idea, then a better approach, then code or a structured design. Stop when
   the time box ends.
4. Review correctness, complexity, and one cleaner alternative. Run the
   solution against a few cases when a runner is available.
5. Write four lines: the problem, the outcome (solved, partial, or stuck),
   the mistake or gap, and the next topic to drill.
6. Do not store company-confidential interview content. Use original prompts
   or problems the user already has rights to practice.
