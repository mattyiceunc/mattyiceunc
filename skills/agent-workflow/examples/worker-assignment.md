# Worker assignment

Adapt this stub. Replace every TODO. Pass the store root and exact paths in
the assignment. Workers do not discover the store on their own.

## Assignment

- Store root: `TODO_STORE_ROOT` (often `/cursor/stores/self/`)
- Owner: TODO_WORKER
- Write only: `TODO_STORE_ROOT/internal/TODO_REPORT.md`
- Do not edit: `TODO_STORE_ROOT/notes.md`
- Done when: the file records the decision, the paths touched, and the check that was run
- Return to the coordinator: outcome, path written, blocker, and what was skipped — not the file body

## Completion report

- Outcome: TODO_ONE_LINE
- Path: `TODO_STORE_ROOT/internal/TODO_REPORT.md`
- Blocker: none, or one sentence and whether retry is safe
- Skipped: TODO_WHAT_WAS_NOT_DONE

## Retry

Use the same assignment and the same path. Do not create
`TODO_REPORT-2.md` on a second attempt.
